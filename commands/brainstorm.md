# Gemini Brainstorm

Generate creative ideas using Gemini's brainstorm tool. You MUST follow every step below.

## Input

- Topic: `$ARGUMENTS`

If `$ARGUMENTS` is empty, ask the user what they want to brainstorm about.

## Step 1: Gather Context

Run:
```
sh "${CLAUDE_PLUGIN_ROOT}/scripts/gather-context.sh" .
```

```
sh "${CLAUDE_PLUGIN_ROOT}/scripts/recent-files.sh" . 30
```

## Step 2: Determine Domain

Infer the domain from the project context and topic:
- If project is Node.js/Python/Rust/Go → domain: `"software"`
- If topic mentions business/revenue/growth → domain: `"business"`
- If topic mentions design/UX/UI → domain: `"product"`
- If topic mentions marketing/growth → domain: `"marketing"`
- If topic mentions research/experiment → domain: `"research"`
- If topic mentions creative/writing/content → domain: `"creative"`
- Default → domain: `"software"`

## Step 3: Build Existing Context

From the project context, build an `existingContext` string that includes:
- Project type and name
- Current branch and recent activity
- Any relevant patterns found via Grep related to the topic
- Recently modified files

## Step 4: Call Gemini Brainstorm

Call `mcp__gemini-cli__brainstorm` with:
- **model**: `"gemini-3-pro-preview"` (MANDATORY - never omit this parameter)
- **prompt**: The user's topic: `$ARGUMENTS`
- **domain**: Inferred domain from Step 2
- **existingContext**: Built context from Step 3
- **ideaCount**: 12
- **includeAnalysis**: true
- **methodology**: `"auto"` (let Gemini choose the best framework)

## Step 5: Present Ideas

Display Gemini's brainstorm results. Add a footer:

```
---
*Ideas generated by Gemini (gemini-3-pro-preview) using brainstorm tool. Domain: {domain}.*
```

## CRITICAL RULES

1. **ALWAYS** pass `model: "gemini-3-pro-preview"` to `mcp__gemini-cli__brainstorm`. Never omit it.
2. Do NOT use `gemini-2.5-pro` or any other model.
3. Always provide `existingContext` with real project data for grounded ideas.
4. Use `includeAnalysis: true` to get feasibility analysis with each idea.
